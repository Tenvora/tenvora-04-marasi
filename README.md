# مَراسي · MARASI — `marasi.qa` (نموذج تصميم)

نموذج صفحة تسويقية واحدة مستقلة (mockup) ضمن سلسلة معرض أعمال Tenvora.
يفتح كملفات ثابتة مباشرة: `index.html` بلا خطوة بناء، بلا Node، بلا صور خارجية.

## ما هذا الموقع
يروي قصة مسار شحنة واحدة عبر أربعة فصول تمريرية كاملة الارتفاع — **الميناء ← الشحن ← التخليص ← المستودع** —
ثم يعرض خطوط الخدمة الأربعة (نقل بحري، تخليص جمركي، تخزين، توصيل أخير) وخريطة مسار بحري.
القطاع: مشغّل لوجستيات مينائية في الدوحة، قطر.

## مدرسة التصميم: N14 — سينمائي Parallax
- لوحة: أزرق بحري عميق `#041427` حتى رمل `#D8C3A5`، مع كهرماني صوديومي `#E9A25C` للإنذار والضوء.
- مشاهد كاملة العرض مبنية من طبقات SVG داخلية (سماء، رافعات، سفينة، حاويات، ماء) — لا صورة واحدة في المشروع.
- حبيبات فيلم (`feTurbulence`) كطبقة علوية `pointer-events: none`.
- مسافات أفقية واسعة، وبُطء في الحركة. المزاج: مرفأ عند الغسق، صناعي هادئ.
- الخطوط: `Changa` (200/400/600/700) للعناوين + `Tajawal` (400/500/700) للنص. التتبّع (letter-spacing)
  يُستخدم على الملصقات اللاتينية فقط؛ كل النص العربي `letter-spacing: 0`.

## المجال (domain) الذي يحاكيه الموقع
لوجستيات الموانئ والنقل البحري في الخليج: أرصفة وعمق غاطس، خطوط ملاحية وناقلات تغذية،
تخليص جمركي ومستندات، مستودعات وأرصفة تحميل، وتوصيل أخير بنوافذ زمنية.
الأرقام والجهات وأسماء الموانئ والشخصيات كلها تجريبية/تمثيلية؛ لا توجد جهة أو مرفأ حقيقي.

## الحركة المميزة: scrollytelling voyage
- كل فصل ٣–٥ طبقات SVG تتحرك بسرعات مختلفة عبر `gsap` + `ScrollTrigger` (`scrub`)، مع تثبيت المشهد
  بـ `position: sticky` بدل `pin` لتجنّب حبس التمرير.
- سكة تقدّم على المسار في الحافة المناسبة لاتجاه RTL (`inset-inline-start` = اليمين):
  سفينة تتحرك على `offset-path`، والمسار يُرسم بـ `stroke-dashoffset` (`pathLength="100"`).
  جسم السفينة معكوس (`scaleX(-1)`) ليواجه اتجاه سيره في صفحة عربية.
- على الشاشات الصغيرة تتحوّل السكة إلى شريط أفقي قصير أسفل الشاشة.

## الوصولية وتدهور لطيف
- `<html dir="rtl" lang="ar">`، الخصائص المنطقية (logical properties) في كل المواضع.
- سطر تخطّي `تخطَّ إلى المحتوى`، حلقات `:focus-visible`، موسّعات خدمة بلوحات مفاتيح أصلية
  مع `aria-expanded` / `aria-controls`، وزر «حركة أقل`.
- `@media (prefers-reduced-motion: reduce)` تعطّل الـ parallax وسكة التقدّم والعدّ وحركة الحبيبات.
- بلا GSAP (أو CDN محجوب) تتحوّل الفصول إلى أقسام عادية وكل المحتوى ظاهر ولا تترجّل أي طبقة خارج الشاشة.
